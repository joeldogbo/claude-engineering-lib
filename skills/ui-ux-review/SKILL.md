# Revue UI/UX

## Instructions

Analyser, indépendamment du framework UI utilisé :

1. **Ergonomie** : le parcours pour accomplir la tâche principale est-il évident ? Nombre d'étapes/clics minimal pour l'action la plus fréquente.
2. **Hiérarchie visuelle** : l'élément le plus important de l'écran attire-t-il l'œil en premier (taille, contraste, position) ?
3. **Cohérence graphique** : espacements, tailles de police, couleurs, composants réutilisés de façon cohérente avec le reste de l'application (pas de style ad hoc qui détonne).
4. **Responsive** : le contenu reste-t-il utilisable et lisible sur mobile/tablette (pas seulement "ne casse pas visuellement") ?
5. **Feedback utilisateur** : état de chargement, erreur, succès visibles et compréhensibles pour chaque action.
6. **Navigation** : retour en arrière possible, état courant identifiable, pas d'impasse.

## Restitution

Constats priorisés par impact sur la tâche utilisateur principale, avec référence au composant/écran concerné. Pour l'accessibilité spécifiquement, voir l'agent `accessibility`.
